# ChallengeME

Mobile-first full-stack outdoor challenge app, designed and built for smartphones with the MERN stack. Protected routes, user profiles and dynamic generation of personalized challenges with MongoDB.

**Live demo:** https://challengemerpb.netlify.app/ · **Portfolio:** https://portfoliobob.netlify.app/#projects

## Features

- JWT route protection & authentication
- Personalized user profiles
- Dynamic challenge generation
- Complete CRUD functionality

**Stack:** React · Node.js · Express · MongoDB · Tailwind CSS
